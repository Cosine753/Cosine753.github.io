At a glance

先说结论

本页和主页都以 NA 匿名身份运行。本站没有登录、评论、订阅或联系表单；演示计算只在当前浏览器内存中完成，关闭页面后不会由本站恢复。

  • 不公开真实姓名、邮箱、单位、教育经历和个人履历目前不放在公开页面。
  • 不上传计算器答案不发送到本站后端，也不写入 cookie、localStorage 或其他浏览器存储。
  • 不追踪页面不加载分析脚本、广告、第三方字体或外部表单；链接跳转到 GitHub 后适用其自身规则。

Data flow

数据经过哪里

下表区分“页面本身的行为”和“外部服务可能拥有的基础记录”，避免把隐私边界说得超过事实。

不同交互的数据流向与边界
交互本站做什么你需要知道的限制
浏览主页、状态页或项目页 返回静态 HTML、CSS 和必要的本地资源，不设置账号或分析脚本。 GitHub Pages 等托管平台可能保留基础访问日志；这不由页面代码控制。
填写风险分层演示 答案只进入当前标签页的 JavaScript 内存，按锁定参数计算后渲染结果。 不要输入真实患者姓名、联系方式、病历号或其他可识别信息；演示不是诊断工具。
打开 GitHub 链接 使用 no-referrer 链接离开本站，不把本站地址作为来源传给目标站点。 离开本站后，GitHub 的账号、日志和隐私政策独立适用；公开用户名本身可能具有关联性。

Public boundary

公开到这里为止

当前版本的目标是验证域名、页面和一项可复核演示，而不是建立完整个人档案。任何身份资料、CV 或直接联系方式都要经过本人复核后才会进入正式版。

现在公开研究主题、方法偏好、项目页面、演示和可核验的版本说明。
暂不公开真实姓名、教育/工作经历、邮箱、电话和未复核的个人陈述。
