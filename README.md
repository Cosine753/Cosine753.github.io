# 个人学术主页

面向 PhD 申请（中国大陆申请-考核制）的单页学术主页。纯静态、零外部依赖——
无 CDN、无 Google Fonts、无跟踪脚本，中国大陆网络环境下可完整加载。

- 线上地址：<https://cosine753.github.io/>
- 本地预览：直接双击 `index.html`

## 文件

| 文件 | 说明 |
|---|---|
| `index.html` | 全部内容与样式都在这一个文件里 |
| `404.html` | 404 页面，GitHub Pages 自动使用 |
| `check.ps1` | **发布前自检脚本**，见下文 |
| `.nojekyll` | 关闭 GitHub Pages 的 Jekyll 处理 |

## 一、你需要填写的内容

页面里凡是形如 `{{需你填写:字段名}}` 的地方都要替换掉。用编辑器搜 `需你填写`
即可全部定位，**共 22 处、12 个不同字段**。

### 必填（不填就不该上线）

| 字段 | 出现处 | 说明 |
|---|---|---|
| `姓名` | 6 处 | 中文姓名。标题、H1、页脚、OG 卡片、JSON-LD 都要 |
| `姓名英文拼写` | 2 处 | 罗马化拼写。**必须与你护照、成绩单、论文署名完全一致**，否则你的成果无法被归到你名下 |
| `现单位与院系` | 2 处 | 如「XX大学XX医院 眼科」 |
| `当前身份` | 1 处 | 如「住院医师」「XX专业硕士研究生」 |
| `邮箱` | 5 处 | 优先用**机构邮箱**；只留一个 Gmail 会让人觉得你没有单位归属 |
| `学位一学校院系与专业学位` | 1 处 | 最高学位在前 |
| `学位一起止年份与补充说明` | 1 处 | 如「2021 – 至今 · 导师：XXX」 |
| `学位二学校院系与专业学位` | 1 处 | 只有一个学位就把第二个 `<li>` 整块删掉 |
| `学位二起止年份与补充说明` | 1 处 | 同上 |
| `如有临床或工作经历请在此说明否则删除本段` | 1 处 | 没有就删掉整个 `<p class="muted edu-note">` |

### 选填

| 字段 | 说明 |
|---|---|
| `ORCID` | 在 `<head>` 下方的联系方式里，默认被注释掉了。去 <https://orcid.org> 免费注册后，删掉注释符启用。**建议注册**——它是唯一能把你和重名者区分开的持久标识符 |

### 填完之后必须做的两件事

1. 删掉 `index.html` 开头那行 `<meta name="robots" content="noindex, nofollow">`。
   在它还在的时候，**搜索引擎不会收录这个页面**，导师搜你的名字找不到。
2. 跑一次 `check.ps1`（见下）。

## 二、发布前自检

```bash
powershell -ExecutionPolicy Bypass -File check.ps1
```

它检查四件事，任何一项不过就返回非零退出码，提醒你先别推：

- **A. 占位符**——还有没有 `{{需你填写:…}}` 没换掉，逐个列出文件名和行号
- **B. 收录开关**——没填完却删了 `noindex`（半成品会被收录），或填完了却忘了删（导师搜不到）
- **C. 外部依赖**——有没有混进 CDN、外部字体、外部图片。你在中国大陆，这类资源会让页面卡住或白屏
- **D. 虚构内容**——初版占位样例里那些内容（虚构姓名、虚构期刊名等）有没有重新出现

脚本是 UTF-8 **带 BOM** 保存的。Windows PowerShell 5.1 读不带 BOM 的中文 `.ps1`
会按 GBK 解码、报莫名其妙的引号错误——如果你要改这个脚本，保存时记得保留 BOM。

## 三、更新与发布

```bash
git add . && git commit -m "更新" && git push
```

推送后约一分钟自动重新发布。

**验证时务必带上随机查询串**，例如
`https://cosine753.github.io/?v=123`。GitHub Pages 走 CDN，直接访问原地址
很可能拿到边缘节点的旧缓存，让你误以为没生效——本项目就踩过这个坑。

## 四、暂未展示的版块

`index.html` 末尾有一大段被注释掉的内容，包含已经写好的「研究工作」和「公开工具」
两个版块。想启用时：删掉该段前后的注释标记，并在页内导航 `.site-nav` 里补一条
对应的 `<li>`。

一条建议：**未投稿论文的头条结论不要放上来**。写研究问题、方法和你做到什么程度是安全的，
把主估计值公开则可能影响后续投稿。真正打动评审的本来也不是结论，而是过程——
核验规模、可复现设施、以及你推翻自己结论时的处理方式。

## 五、还可以补强的地方（按性价比排序）

1. **CV PDF**。招生委员会几乎一定会找可下载的 CV。做好后放在仓库根目录、命名固定为
   `cv.pdf`，在页面顶部加一个带更新日期的链接（「CV（PDF，2026-07 更新）」）。
   **不要放网盘链接**——权限墙会把海外和大陆读者分别挡在外面，而固定文件名能让旧邮件里的链接一直有效。
2. **注册 ORCID**，并在页面和 CV 上都放出来。
3. **英文版**。你的目标是大陆申请-考核制，中文为主是对的；但若之后要投海外项目，
   加一个 `en/index.html`，并用 `<link rel="alternate" hreflang>` 双向互链。
4. **OG 卡片图**。导师把链接贴进邮件或微信时会显示。做一张 1200×630 的 PNG
   存为 `og.png`，在 `<head>` 加 `<meta property="og:image" content="https://cosine753.github.io/og.png">`。
   注意要用本地文件路径，**不要用 data URI**——不少平台不认。
5. **Google Search Console / Bing 站长平台**注册本站点。平时用不上，但万一出现需要
   紧急撤下的内容，你能在几小时内提交移除请求，而不是在申请季才发现。
